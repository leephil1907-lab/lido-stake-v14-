# Lido Staking & Wrapping dApp

A decentralized application for liquid staking and token wrapping on Ethereum.

## Features

- **Stake ETH**: Liquid stake ETH to receive stETH rewards.
- **Wrap & Unwrap**: Convert stETH to wstETH for DeFi compatibility and unwrap back at any time.
- **Withdrawals**: Request and claim stETH / wstETH withdrawals.
- **Multi-Wallet Support**: Connect seamlessly with MetaMask, WalletConnect, Coinbase Wallet, and other Web3 providers.
- **Sepolia & Mainnet Ready**: Configured for testing on Sepolia testnet and Ethereum Mainnet.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
